这是什么

一个会把 KAM 的判断沉淀成个人方法论库的工作台。前期教你判断，中期记录你的判断与反馈形成复盘， 后期用你自己沉淀的方法论替你判断——并且这套库能导出给新人，让没经验的人也做出同水平判断。

两个视角

视角给谁看看什么
老板视角站点负责人 / 总部一页战报：一句话态势、出货 / 有效完成率 / 收入 / 运价 / 需关注账户、客户健康度、欠量该找谁、风险 / 机会 / 提请决策、判断靠不靠谱。只读，数字全部来自执行视角的录入与人工确认的归因
执行视角KAM 本人每月工作流：复盘回填 → 口径声明 → 导入数据 → 四维度诊断 → 逐条归因 → 重点客户 → 总部报告。顶部进度条显示本月做到哪一步，点哪步跳哪步

老板视角里，未经人工确认的归因一律标「待确认」，并提示「确认前不建议据此决策」——人工放行闸门在两个视角之间同样生效。

四阶段演进

阶段角色做什么
①教练逼你过完四个维度、逼你每条归因填证据，不让你凭感觉下结论
②记录者把每次判断、理由、证据存下来；下月回来标记判断准不准
③复盘器把反复出现且验证为准的判断模式，提炼成你自己的心法条目
④代判者新条目进来先查心法簿找相似先例，给出「上次这么判、结果如何」

它和普通 AI 分析工具的区别

它替你判断时，依据是你自己沉淀的判断记录，不是凭空推测。 所以归因不会胡说——库里没有相似先例就老实说没有，转教练模式让你做新判断，新判断又进库。

判读标尺

灯完成率区间定级是否需要行动
< 60%严重不足需要，本月处理
60% ~ 79%不足需要，本月跟进
80% ~ 100%正常不需要，观察
> 100%超额视情况，关注运力与定价

偏差绝对量另有标尺：<10 吨轻微 / 10~50 吨中等 / >50 吨重大。百分比定性质，绝对量定优先级。

红线

  • 相关性不等于因果——无证据的归因一律标「待人工确认」，不得写成结论
  • 无成本数据不谈利润，只评价收入与价格质量
  • 归因必须人工放行，机器只给候选
  • 心法簿无相似先例时明说没有，绝不编造
  • 总部版走白名单，不靠事后删敏感信息
  • 完整月与月中快照不混比
  • 判断记录全部存在本机浏览器，不出网

数据存在哪

全部存于本机浏览器 localStorage，不联网、不上传。清空浏览器数据会丢失， 重要内容请用心法簿页的「导出」留存。
