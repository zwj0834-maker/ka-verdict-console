# KA 履约心法簿 · 长期合同偏差归因与判断沉淀工作台

职场AI武林大会参赛作品（HTML 工作台）。

## 在线体验

打开本仓库的 GitHub Pages 链接即可使用，首次打开自动载入演示数据。

- **老板视角**：月度履约战报，只读。包括一句话态势、核心指标、客户健康度、欠量去向、风险 / 机会 / 提请决策
- **执行视角**：每月工作流，依次是复盘回填 → 口径声明 → 导入数据 → 四维度诊断 → 逐条归因 → 重点客户 → 总部报告

## 本地运行

下载 `index.html`，双击用浏览器打开即可。无需安装任何环境，断网可用。

## 数据说明

- 单文件、零外部依赖，不调用任何外部接口
- 所有数据只存在使用者本机浏览器（localStorage），不上传
- 演示数据中的客户均为虚拟标识（示例-甲货代 等），数字为演示编造，不对应任何真实客户与经营数据
